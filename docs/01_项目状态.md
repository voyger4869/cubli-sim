**三条根问题**（详见 [`03`](03_未解决与已证伪.md)）：

1. **倾角会缓慢漂移、最终翻倒。**`fast` 约 4 分钟、`wheel_stop` 约 700–800 s、
   `wheel_stop_yaw` >1200 s。**先到极限的是倾角，不是轮速。**两个步长下形状相同 ⇒ 是物理的。
2. **偏航消除不了**（守恒）：绕竖直轴没有外力矩，唯一的摩擦实测是**净注入方**。
3. **被控对象数值未收敛**：步长再减半到 0.125 ms，同一配置会翻倒。

## 二、架构

**一台被控对象服务所有模式**：自由 6-DOF 方块 + 真实罚函数接触 + 三只全部电机化的飞轮 +
全套传感（`SenseR` 姿态、`SenseOmega` 角速度、`SenseXYZ` 质心，三个关节轮速、接触穿透）。
一个控制块按 `P.run.modeCode` 派发。

**切换功能不需要重建 `.slx`**：初值、停止时间、模式编码、**全部控制常数**都以
**工作区表达式**读取（`P.run.ic.*`、`P.run.modeCode`、`P.run.duration`、`P.run.ctrl`）。
块的对话框参数写成 `P.run.mode` 这类表达式，`run_cubli_clean` 把 `P` 放进 base 工作区。
唯一**例外**是接触求解器的档位与步长——那两个是**建模型时烤进去**的，改 `P` 对已建好的模型无效。

**可选平衡预设**（`P.run.balancePreset`，内容见 [`../src/core/cubli_clean_parameters.m`](../src/core/cubli_clean_parameters.m)）：

| 预设 | 含义 |
|---|---|
| `fast` | 出厂行为。飞轮爬到 ~950 rad/s 后**冻结**（不是收敛慢，是结构性的）。**已验证，不允许改动。** |
| `wheel_stop` | 加**转速积分**把飞轮压到 40–60 rad/s。需要接触求解器 0.25 ms。 |
| `wheel_stop_yaw` | 同上 + 柔和 X/Z 偏航保持。偏航减半、寿命翻倍，代价是 X/Z 线性增长（600 s 到 ±84 rad/s）。 |
| `edge_low_speed` | 棱模式专用；ODE5 @ 0.125 ms，平放起立后 30–300 s 的 Y 轮约 6–8 rad/s。 |
| `edge_near_zero` | 棱模式专用；同一求解器，连续稳定捕获 2.278 s，300 s 末 30 s 的 Y 轮 −0.73 到 +1.73 rad/s。接触漂移和步长敏感性未解决。详见 [`06_棱平衡低轮速控制设计.md`](06_棱平衡低轮速控制设计.md)。 |

## 四、这个项目反复踩到的三条原则

**1. 状态量必须是活的。**顶点模式一度整段结论失效，根因不是符号也不是增益，而是
**判定和控制的那个状态量本身没有信息**：顶点无摩擦 ⇒ 水平力为零 ⇒ 质心不能平移 ⇒
`asin(com_x/h)` 恒为常数。**这类错误不会报错**——形状对、数值平滑、门槛能过。
现在的常规检查是：**报出该状态量在整个过程里的变化范围**，范围为零就是死信号。
同理，判据必须能区分方块可能稳定到的**所有**姿态（0.12954 / 0.10570 / 0.07464）。

**2. 任何接触相关数字都必须连求解器档位一起记录。**理想族用 ODE1 @ 2 ms，接触族用 ODE3 @ 1 ms，
**跨族的数字不可比**。这条写过、违反过、代价是一整条主线作废。

**3. 参数"设了"不等于"生效"。**已知的失效方式有五种：改名后旧字段失效、
在**建模型时**读入的参数改 `P` 无效、预设里残留旧值、`{'a',1,'b',2}` 是 **1×N cell**
（只读第一对，其余静默丢弃）、以及只看单个通道。**现在所有扫参脚本都带回读断言。**
