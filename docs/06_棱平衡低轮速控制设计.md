# 棱平衡低轮速方案与验证记录

更新：2026-10-03。范围：`edge_balance` 和 `stand_to_edge`；既有预设的参数和默认选择保持原状，新预设独立选择。

## 用户目标与可操作结论

用户允许方块从平放到棱平衡用 **3 s**，希望平衡后 Y 飞轮逐渐接近零速，只作小幅稳定修正。当前可复现的方案是新增预设 **`edge_low_speed`**：沿用原起立、捕获和棱平衡控制律，将 Y 轮转速积分增益 `KiEdge` 从 `3e-5` 调到 `8e-5`，并对这一预设使用 **Simscape Multibody 局部求解器 ODE5 @ 0.125 ms**。当前默认预设、`fast`、`wheel_stop`、`wheel_stop_yaw` 的控制路径不变。新预设只支持两种棱模式，选到其他模式会报错。

在 MATLAB 项目根运行 `setup_cubli`，将 `src/core/run_cubli_clean.m` 顶部设为：

```matlab
cubliMode = "stand_to_edge";      % 也可选 "edge_balance"
cubliPreset = "edge_low_speed";
cubliSeconds = 300;              % 可先用 30 或 90 s 观察
```

入口脚本会自动把 Solver Configuration 块设为 ODE5 @ 0.125 ms 并回读断言。单独调用 `cubli_mode` 后直接 `sim` 时，必须也设置模型块上的求解器选项；只改 `P.sim.localSolver` 不会改变已生成模型的块参数。

发布目录另提供快速验证，先 `setup_cubli` 再运行：

```matlab
verify_edge_low_speed("stand_to_edge",30)
```

该脚本检查 3 s 内捕获、末段 Y 轮速度、随棱倾角和接触高度，同时打印三轮合成转速。发布目录实测 30 s：捕获 **1.171 s**，Y 轮末速 **6.65 rad/s**，末段三轮合成速度最大 **9.00 rad/s**，随棱倾角末值 **−0.0126°**，`ok=1`。发布目录的 300 s 复测也通过：Y 轮末速 **7.49 rad/s**，末段三轮合成速度最大 **7.77 rad/s**，随棱倾角末值 **−0.0073°**。下面的开发副本诊断命令可打印更细的时间轨迹：

```matlab
setup_cubli
exp_edge_zero_baseline('edge_low_speed',300,cell(0,2), ...
    'stand_to_edge',0.000125,'ODE5')
```

捕获时间定义：质心高度达到棱高度区域，随棱倾角绝对值 `<2°`，绕棱角速度绝对值 `<0.2 rad/s`，**连续保持 0.2 s**；表中给完成时刻。完整起立实验在 0.366 s 首次达到棱高度、0.874 s 首次瞬时满足姿态与角速度条件、1.171 s 连续满足。起立的短暂轮速峰值约 317 rad/s；到第 8 秒降到 8.6，第 30–300 秒维持约 6–8。这满足“允许 3 s 内立起来、之后几乎不转”的目标，而不是要求起立冲量阶段也零速。

300 s 完整起立实验中，随棱倾角在第 30/60/120/180/300 秒为 −0.013/−0.001/+0.007/−0.007/−0.007°；Y 轮对应为 6.7/6.1/6.4/7.5/7.5 rad/s。第 300 秒 Y 轮速为电机最大轮速 1800 rad/s 的约 0.42%。同时，偏航累积至 −6.748°，接触线位移代理量约 8.21 mm；这两项尚未消除，不能把该预设称作“无限时间完全静止”。

## 为什么此前判断反复变化

### 控制问题确实存在，但不能只调起立速度

旧 `fast` 在 ODE3 @ 1 ms 下，从平放起立的第一次稳定进入门槛约 1.194 s；第 3 秒 Y 轮约 38.8 rad/s，第 8 秒已约 283.8 rad/s，3–8 秒平均 Y 力矩约 +4.90 mN·m。因此爬升发生在捕获之后，不是因为起立太快。`edge_balance` 从棱上、近零轮速起步也会爬升，进一步排除了起立瞬态是唯一来源。延长允许捕获时间本身不能消除平均力矩。

控制律沿用以下结构（`s=-1`，`theta_com=asin(com_x/d)`）：

```text
tau_y = s*(Kp*theta_com + Kd*omega_y)
        + Kw*wheel_y + KiEdge*integral(wheel_y)
```

`fast` 的 `KiEdge=0`；原 `wheel_stop` 为 `3e-5`；新预设为 `8e-5`。增大轮速积分作用可抵消长期平均力矩，让轮速回到低值。先前直接叠加一个受限的轮速 PI 修正（`zero_3s_trial`）在 8 秒看起来更好，第 30 秒却回到约 1017 rad/s；它因修正力矩约在 38 rad/s 就饱和，并没有形成有效的长期轮速调节。改姿态单反馈、姿态/质心线性混合、滑移速度项或直接反转轮速反馈也未通过长时试验。

### 原来的“真实倾角”读法在偏航后不成立

早期报告用 `atan2(R13,R33)-π/4` 当棱倾角。它只在棱轴始终沿世界 Y 方向时成立；方块绕世界 Z 轴偏航后，棱轴也转动，这个式子把偏航误读成倾斜。ODE3 @ 0.125 ms 的第 60 秒，旧式子给出 **−7.253°**，但随棱坐标算出的真正倾角为 **+0.002°**，偏航是 **−39.273°**。因此旧式子不能用于长时平衡验收。

新诊断从姿态矩阵得到方块“向上”的体对角向量 `u=R*[-1,0,1]/sqrt(2)` 和棱轴 `e=R*[0,1,0]`；在水平面取棱法向 `n=[e_y,-e_x,0]/hypot(e_x,e_y)`，用 `atan2(dot(u,n),u_z)` 得到随棱倾角。沿棱方向倾角和棱偏航另行报告。旧报告字段保留供旧版本对照；`edge_low_speed` 的验收使用随棱倾角，并检查 Y 轮末段速度。

### 求解器是方案的一部分

相同 `KiEdge=8e-5` 在 ODE3 @ 0.125 ms 下会在 60–120 秒翻倒，ODE5 @ 0.125 ms 却通过 300 秒完整起立试验。ODE5 @ 0.25/0.125/0.0625 ms 的 120 秒结果都低轮速、直立，但具体轮速与偏航**没有随步长单调收敛**。因此这是一个**在指定数值配置下可复现的工程候选**，不是已经证明的连续时间物理系统解。不能把 ODE3 的失败简单归咎于 PID，也不能把 ODE5 单一档位的成功当作接触模型精度证明。

## 验收边界与后续工作

`edge_low_speed` 现阶段的可验收声明限定为：ODE5 @ 0.125 ms、当前接触参数、`stand_to_edge`/`edge_balance`、最长已测 300 s 的完整起立。Y 轮在 30–300 s 约 6–8 rad/s，方块保持棱平衡。项目仍需继续处理偏航和接触线位移、检查 X/Z 轮全时程，并改进接触模型的步长收敛性。达到这些要求前，不宣称“所有飞轮严格零速、永久静止”或“真实硬件也会得到同样数字”。

GitHub 发布目录已加入该独立预设和 `src/verification/verify_edge_low_speed.m`；`fast` 仍是默认预设。发布入口在临时选择 `edge_low_speed` 后实跑 30 s，自动选择 ODE5 @ 0.125 ms、正确覆盖 `stand_to_edge` 时长，报告 `ok=true`；普通参数复测的 `P.run.ctrl` 仍为原来的 58 项。发布说明须同时列出有效求解器配置与上述限制。

## 2026-10-03：零附近调节的追加实验

用户指出 `edge_low_speed` 长期保持 5–10 rad/s 且很少过零，希望稳定后在零附近小幅正反调节。这个目标在动力学上有意义：零轮速可以是理想棱平衡的平衡点，但**某一组参数能保持 +7 rad/s，并不能逻辑推出微调后一定稳定在 0**。飞轮卸速的力矩同时作用于方块，接触点移动、偏航和积分状态会反馈到下一次调节。

先在开发副本试了独立的稳定后小力矩反向刹车。最大力矩 0.005 N·m、转速增益 `5e-4` 的 30 s 试验确实过零并到达 −11.7 rad/s；120 s 又回到 +29.5 rad/s。将增益扫到 `1e-4`、`2e-4`、`3e-4`、`4e-4` 后，`3e-4` 在 300 s 的末 30 s 均值仍是 +5.96 rad/s，范围 −9.92 到 +20.05 rad/s。积分泄漏率 0.02 和 0.1 /s 使 120 s 末段均值分别升至约 +21.8 和 +63.1 rad/s。**所以“加刹车后曾经过零”没有解决近零稳态问题；这段试验代码已从控制器撤除。**

随后只改变原控制律的 Y 轮转速积分增益 `KiEdge`，保持 `Kp`、`Kd`、`Kw`、起立阶段、接触模型及 ODE5 @ 0.125 ms 不变。新增独立预设 `edge_near_zero` 取 `KiEdge=1e-3`；`edge_low_speed` 继续取 `8e-5`，原预设均不改。新预设仅支持 `stand_to_edge`、`edge_balance`，入口脚本自动设置 ODE5 @ 0.125 ms。控制参数向量仍为 58 项，没有增加控制律分支或输出刹车项。

`edge_near_zero` 的 300 s 试验末段三轮速度范数最大值也为 1.73 rad/s，末时随棱倾角约 +0.001°，偏航约 −6.737°，接触位移代理量约 8.0 mm。它在 8 s 后多次过零；过零计数达数千次，主要说明接触仿真存在高频小幅波动，**不是慢速、规则的“摇摆控制”证据**。较大积分增益让起立过渡明显更摆动：约 2 s 时随棱倾角 +2.38°，约 3 s 时 −1.99°，连续稳定捕获仍在用户允许的 3 s 内。

`edge_balance` 从棱上直接起步，`edge_near_zero` 在 120 s 末 30 s 的 Y 轮范围为 −0.80 到 +1.91 rad/s、均值 +0.57 rad/s，末时接触位移代理量约 3.37 mm。另以 ODE5 @ 0.25 ms 和 0.0625 ms 运行平放起立 120 s：前者末 30 s 范围 −1.78 到 +5.18 rad/s、接触位移约 9.5 mm；后者范围 −0.98 到 −0.68 rad/s、偏航约 −11.1°。三档结果**没有数值收敛**。因此当前最窄的可靠表述是：在指定 ODE5 @ 0.125 ms、现有接触参数下，`edge_near_zero` 在 300 s 内把三轮速度降到约 ±2 rad/s 并保持棱平衡；它尚不能证明真实系统或无限时长严格停轮。

根因分析：控制器仍把 `asin(com_x/d)` 当棱倾角。实际姿态接近零时，这个量随接触位移从约 0 上升到 300 s 的约 4.2°；它与持续累积的 `KiEdge*∫w_y dt` 在力矩中互相抵消。提高增益把同一残余偏置对应的轮速压低，但**接触漂移与偏航并未随之消失**。下一阶段应把随棱姿态、接触点位移和轮速作为不同状态来观测和反馈，校正接触模型的步长敏感性，再讨论严格的零速渐近收敛。
