> **2026-10-03 更正：**下文部分长期“真实倾角”数字使用
> `atan2(R13,R33)-45°`。它在棱轴发生偏航后不再是绕棱倾角，会把偏航读成倾斜。
> 例如 ODE3 @ 0.125 ms 的第 60 秒，旧值 −7.253°，随棱坐标的倾角仅 +0.002°，
> 棱偏航 −39.273°。因此下文把固定轴角度漂移解释为真实倾覆趋势或接触力成因的推论
> **尚未成立**；真实翻倒仍应以质心高度和随棱倾角确认。新预设及跨求解器数据见
> [`06_棱平衡低轮速控制设计.md`](06_棱平衡低轮速控制设计.md)。下方历史实验数字保留作溯源。

每一条都带原始实测数字与出处，因为"为什么不行"比"不行"有用得多。

# 一、未解决

## 1.1 【根问题】倾角会缓慢漂移，最终翻倒

**先到极限的不是飞轮转速，是倾角。**三个预设都只是"撑多久"的差别：

| 预设 | 600 s 时倾角 | 1200 s 时倾角 | 寿命 |
|---|---|---|---|
| `fast` | −14.5° | — | **约 4 分钟翻倒** |
| `wheel_stop` | 约 −3° | — | **约 700–800 s 翻倒** |
| `wheel_stop_yaw` | −6.1° | −24.4°（仍在加速） | **>1200 s，但也会倒** |

出处：`src/experiments/exp_falltime.m`、`exp_ws_hold.m`、`exp_yawfix.m`。

**为什么它要紧**：出厂的 `edge_balance` 只跑 10 s 验收，**从来看不到这条漂移**。
它在**两个步长下形状相同**（0.5 ms 与 0.25 ms），所以是**物理的**，不是步长伪影。

**已知的一件事**：漂移在**随倾角加速**，说明扰动本身随倾角变大——
很可能是接触力沿棱的分布不对称（倾斜后接触点移动，不对称随之变化）。**未证实。**

## 1.2 【根问题】偏航消除不了（守恒）

方块平衡时以约 **−0.098 °/s** 恒定自转（600 s 累积 −59°，几乎完美线性 ⇒ 恒定力矩）。
**这在物理上无法消除**：

- 绕竖直轴**没有外力矩**可以吸收动量——重力竖直、接触法向力也竖直；
- 唯一的接触摩擦实测是**净注入方**（见 1.3）；
- 轮子只能把动量**存起来**，而"永远存着"就是线性无界增长。

`wheel_stop_yaw` 把它减半、寿命翻倍，**但不改变这个结论**。

## 1.3 偏航的扰动力矩有已知成因，但只能治标

实测偏航偏置力矩 **1.3e-5 N·m**。成因是**摩擦**：

| 配置 | 偏置 |
|---|---|
| 基线 μ 0.72/0.55 | −1.28e-5 N·m |
| **μ = 0** | **−1.8e-8 N·m**（塌掉 700 倍）|
| μ 0.9/0.8 | **−9.7e-5 N·m**（**更糟 7.5 倍**）|
| 轮子质量 → 0 | **与基线逐位相同** |

出处：`src/experiments/exp_yawcause.m`。

**所以：增大摩擦会让它更糟；质量分布无关**（模型的**一阶矩按构造就精确为零**，
`wheelCenters` 三项和为 [0 0 0]）。它是接触切向力沿棱分布里一个固定的不对称。

## 1.4 被控对象在数值上未收敛

这是**前提性问题**，详见 [`02_测试协议.md`](02_测试协议.md) 的"求解器步长"一节：

| 步长 | 同一配置的结果 |
|---|---|
| 0.5 ms | 纹波 245，立着 |
| 0.25 ms | 纹波 **1.7**，立着 —— **看起来完美** |
| **0.125 ms** | 纹波 1808，**翻倒** |

变化是**爆炸**而不是缩小，所以 0.25 ms 只是未收敛序列里一个走运的采样。
**不要再靠调步长去改善结果。**

## 1.5 两个模式验收未通过

- **`walk`（行走）**：能走出 6.97 个面（7 步），但 `facesOk` 与 `penetrationOk` 不达标。
  驱动量在 0.56–0.80 之间扫，步数从 0.01 跳到 9.04，**不稳健**。
- **`stand_to_point`**：飞轮冲到 **3129 rad/s**（上限 1800 的 174%）。这是**非本轮引入**的既存失败。

## 1.6 长期横向滑移

`com_x` 在 300 s 内漂 0 → 55 mm，看不出有界。不构成翻倒风险
（沿接触线滑动几何上可存活），但是**没有指令的运动**，且远超既有口径 `comXYDriftMax = 5e-3`。

# 二、已证伪（试过、失败、不要再试）

## 2.1 让飞轮转速稳定到 0 的各种尝试

| 试过的 | 结果 | 出处 |
|---|---|---|
| **力矩死区** `dz = 0, 0.002, 0.005, 0.01, 0.02` | 全部停在 895–999 rad/s，**无效** | `exp_deadband.m` |
| **倾角积分** `KiTilt = 0/0.01/0.03` | 爬到 913–971；`0.1/0.3` 翻倒 | `exp_tiltint.m` |
| **改用姿态倾角做反馈** | 配 `Kw>0` 飞轮跑到 −1665；配积分 80 s 翻；配 `Kw=0` 30 s 翻平 | `exp_nopump.m` |
| **从平衡姿态起步**（`initialTiltDeg = 0`）| 照样爬到 1005 ⇒ 爬升不是"重力为初始偏置付账" | `exp_pump_src.m` |
| **比例式倾角给定串级**（姿态倾角，`Kw = −2.2e-4`）| 15 s 内翻倒，而线性化预测它稳定 | `exp_edgemode.m` |
| **泄漏积分** `lamW = 0…2` | 每一条都停在 −6° 和 ~110 mm，**无效** | `exp_wzero.m` |
| **偏航阻尼单用** | 比出厂更差（1775 对 971）| `exp_yaw.m` |
| **偏航回调** `YawRateRef = 0…−0.5` | 确实限住了轮速，但两条漂移都变差 | `exp_callback.m` |

**为什么死区无效（这一条有普遍意义）**：泵不是"力矩小"，而是**力矩的时间平均非零**；
力矩在两个方向摆幅都很大，按幅值筛选会把这摆幅原样放过去，**净值不变**。
**只有积分器能去掉时间平均。**

## 2.2 关于棱→顶点与直跳

- **冲量式两段抬升**（储能 → 急刹）在棱→顶点上**全部失败**：`spinW` 从 600 扫到 1800，
  七个值**全部 fell flat**（出处 `diag_cubli_edgetopoint.m` 的输出）。
  **有效的是"只用律"那一版**：`spinSpeed = 0`，让控制律自己完成爬升。
- **平放→顶点直跳**（冲量版）：`spinW` 900–1800 扫过，**1800 时冲出棱外**；
  律版（`lawonly`）能到顶点。该模式仍是**实验级**，未升格。
- **分离的爬升增益**：采样的 **40 组组合全部失败**，包括原本不加它也成功的那些。
  机理：降低爬升增益 → 爬得更慢 → 重力作用更久 → 需要**更多**轮动量。
  **在这台被控对象上，"温和"一律更差。**

## 2.3 关于根因的误判

- **`I_xy = −1.5e-4` 是偏航的根因**？**早在本项目 [`history/CUBLI_G2A_TEST_PROTOCOL.md`](history/CUBLI_G2A_TEST_PROTOCOL.md) 就被证伪**：
  删掉三只飞轮做成完美对称体，ODE1 偏航只从 302° 降到 61°，而**对称刚体不可能物理自转**；
  驱动量是积分器，`I_xy` 只是个约 5 倍的放大器，ODE3 会把它抵消。
- **`Kw` 越大末速越低**？**错。** 那张 `Kw = 0 → 1908 / 2e-4 → 432 / 5e-4 → 205 rad/s` 的表
  是在 **10 s 瞬态**上读出来的。`Kw` 只改变零力矩点的位置（`θ = Kw·w/Kp`），
  **它让飞轮到得更晚，不是更低**。
- **轮位不对称是根因**？见上一条，同一个实验。
- **偏航动量可以甩掉**？**不能**，见 1.2。轮子能把动量搬回方块，但搬不出系统。

## 2.4 关于求解器

- **关掉机构局部求解器、交给自适应刚性求解器**：**不可行**。
  自适应求解器照样被刚度逼到约 1 ms，但每步代价大得多——20 s 的仿真跑了几分钟才到 3%。
  局部求解器是**性能上正确的选择**。
- **`MultibodyLocalSolverChoice` 有隐式选项吗**：没有，只有 ODE1..ODE8（全显式）。
  Simscape 网络级的局部求解器（`UseLocalSolver`）确有隐式选项，但**实测是空操作**：
  开成梯形法或后向欧拉，净偏航四位小数都不变。

# 三、撤回与更正记录

**这一节记录的是"我说过、后来被自己推翻"的结论。**留在这里而不是删掉，

## 3.1 三次撤回（2026-09-27 那一轮）

| # | 我报过的 | 为什么错 | 正确度量是什么 |
|---|---|---|---|
| 1 | "`wheel_stop` 成功了" | 只读了 `w_y` **一个通道**。带偏航项时动量只是**搬到了 X/Z 那一对**：Y 971 → 34，X/Z 到 ±573，**三轮范数反而峰值 2386** | **三轮范数**，不是单通道 |
| 2 | "偏航打死一切甩轮尝试，且偏航动量根本甩不掉" | 是在**接触求解器 1 ms** 下得出的，而那里的偏航**大部分是数值伪影**（能立住的基线自己在 1 ms 读 −0.3°、0.5 ms 读 −18°、ODE1 读 2947° 并翻倒）| 换步长复测 |
| 3 | "0.25 ms 的结果就是答案" | 那确实是抖动消失的地方，但 `exp_conv` 显示**序列不收敛**（0.125 ms 翻倒），所以它只是一个采样 | 收敛性检验：**收紧参数看结果动不动** |

**共同教训**：**先确认你读的是不是你想的那个量，再下结论。**
这一轮里"参数没按预期生效"一共犯了 **5 次**：
`run.edge.Kyaw` 改名后失效、只看单通道、`P.sim.localSolver` 在**建模型时**被读入（循环里改无效）、
预设里残留了 `Kyaw = 0.3`、以及 `{'a',1,'b',2}` 这种 **1×N cell**（`cubli_mode` 只读第一对，**静默丢弃其余**）。
**现在所有扫参脚本都带回读断言。**

## 3.2 `reshape` 陷阱（两个结论作废）

早期诊断脚本用 `reshape(Data, N, [])` 读 `cubli_com`。但 `To Workspace` 存的是 **3×1×N**，
MATLAB 的 `reshape` 是**列优先**的，这个写法会把三个分量按时步**交错**，
得到"每行是三个分量的重复"而不是一个样本。

作废的两条：

- ~~"COM 每 4 ms 在 (0,0,0.1057)/(0,0.1057,0)/(0.1057,0,0) 之间循环"~~ —— reshape 假象。
  原始日志平滑：com_x=0.00185、com_y=0、com_z=0.10569。
- ~~"棱接触存在剧烈颤振（com_x 峰峰 0.1057）"~~ —— 同上。

`cubli_contact_report.m` / `cubli_run_report.m` / `cubli_log_reshape.m` 用的是 `reshape(Data,3,N)`，是对的。

## 3.3 "10 s 验收"其实只跑了 2 s

`P.run.point.duration` 一度是 **2.0**，而 `cubli_mode` 把它拷进 `P.run.duration`、
`StopTime` 读的正是它——**与此同时 builder 的横幅按默认参数打印 "10.0 s"**。
于是每一轮所谓"10 s 顶点门槛"的运行都静默地只跑了 2 s，**一整轮结论建立在 2 s 上**。
现已改为 10.0，并在参数文件里记了这一段。

## 3.4 我自己测量里的其它错

- `exp_wpark` 一度把 `flat_to_point` 报成 "NOT BALANCED"——**我的错**：
  该链落在 **(−1,1,1)/√3** 顶点，而我按 (1,1,1)/√3 算倾角。用正确酉轴复测：稳定通过。
- `travelAxis` 与速率轴混用（绕世界 Y 转 ⇒ `ω_y` 是分量 2，但质心沿 x 是分量 1），
  一度把行走位移报成 0.73 个边长（应为 7.11）。
- 一次"变步长对照"跑出八个结果**逐位相同**——那不是物理结论，是**设置根本没生效**
  （`P.sim.localSolver` 建模型时被读入）。**八个结果完全相同就是 no-op 的样子。**
