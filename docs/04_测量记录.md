# 测量记录

这份文件把原先散落在 69 个 `.txt` 日志与 7 个 `.mat` 快照里的**原始测量数据**集中起来，
去掉了 MATLAB 的控制台横幅噪声（`Created D:\...slx`、`=== MATLAB 24.2 ... ===` 之类），
数值一字未改。**原始的 `.txt`/`.mat` 已删除**——本文是它们的内容。

**大多数日志都能由 `src/` 里的脚本重新跑出来**，每一节标注了对应的脚本。
标了「无脚本」的是当时随手写的探针，跑过之后就没了，只有这里的数据。

> 关于绝对值可信度的一条通用告诫：本项目多次发生「同一个配置在两个脚本里量出不同数字」，
> 已知的一个来源是控制器图表的 persistent 变量在同一个模型上连续 `sim` 时可能不复位。
> **量级与趋势可信，个别绝对值的最后几位不要当回事。**

来源：`audit.txt`，脚本 `src/diagnostics/diag_cubli_plausibility.m`

```
=== 1. 质量与几何 ===
方块 0.500 kg，边长 0.150 m -> 密度 148.1 kg/m^3（轻木约 150，水 1000）
轮 3 x 0.080 kg = 0.240 kg，占 0.740 kg 装配体的 32%
轮半径 0.050 m = 方块半边长 0.075 m 的 0.67
轮心（X/Y/Z 三行）：
    0.0500    0.0250         0
   -0.0250   -0.0500         0
   -0.0250    0.0250         0
轮心之和 = [0 0 0]（一阶矩为零）
沿各自自转轴的偏置：X +0.050，Y -0.050，Z +0.000
  -> 真实 Cubli 把三只轮各装在一个面上，三个偏置应当接近且非零。这里 Z 是零。

=== 2. 绕质心的惯量 ===
    0.0022   -0.0002         0
   -0.0002    0.0022         0
         0         0    0.0025
装配体惯量：Ixx 2.1830e-03  Iyy 2.1830e-03  Izz 2.4830e-03  kg*m^2
方块单独为 1.8750e-03 ；轮子给 Ixx 增加 14%
Ixy = -1.500e-04（文档记录值），Izz/Ixx = 1.137

=== 3. 执行器规格 ===
连续 0.060 N*m ；峰值 0.800 N*m ；比值 13.3 倍
转速 1800 rad/s = 17189 rpm
功率：连续 108 W，峰值 1440 W（满速）
峰值力矩下加速到满速：0.225 s ；连续力矩下：3.00 s
  -> 0.74 kg 机体上 1440 W 峰值属于无人机量级；这个尺寸的真实反作用轮远低于此。
     规格在内部是「过于充裕」的，这对动作有利，所以它不是瓶颈。

=== 4. 重力矩尺度 vs 可用力矩 ===
平放（支点 = 底面棱）  力臂 0.07500 m  重力矩 0.5445 N*m
                       连续/重力 = 11.0%   捕获带 6.33 度
棱（支点 = 接触棱）    力臂 0.10607 m  重力矩 0.7700 N*m
                       连续/重力 =  7.8%   捕获带 4.47 度
顶点（支点 = 接触角）  力臂 0.12990 m  重力矩 0.9430 N*m
                       连续/重力 =  6.4%   捕获带 3.65 度
  -> 连续力矩只有重力矩尺度的约 6%。倾角控制器只能纠正这个带以内的倾角。

=== 5. 所需动量 vs 储存能力 ===
平放 I_pivot 6.3455e-03 ；棱 1.0508e-02 ；顶点 1.4670e-02  kg*m^2
平放->棱 能量 0.2255 J ；棱->顶点 0.1730 J ；平放->顶点 0.3986 J
棱姿态下每单位转速沿世界轴提供的轮动量：
  dL/dw 绕世界 X = 2*1.0e-04*0.5 = 1.0e-04（Wheels X 与 Z；Y 为零）
  1800 rad/s 时能力 = 每只轮 0.1800，成对 0.3600 kg*m^2/s
  棱->顶点需要 I_pivot*dw = 1.4670e-02 * 4.86 = 0.0713 kg*m^2/s
  -> 用完重罚之前只用掉成对能力的 20%

=== 6. 接触 ===
刚度 2.0e+04 N/m，阻尼 160 N/(m/s)
静态穿透 0.3630 mm = 边长的 0.242%
接触阻尼比 zeta = 0.658
摩擦 静 0.72、动 0.55
```

## 7. 参数快照对比（由 7 个 `.mat` 转成）

脚本 `src/diagnostics/diag_preset_baseline.m` + `diag_preset_compare.m`。
每次改动控制器图表后跑一次，把 8 个模式的全部数值字段快照下来，与旧快照**逐字段**比对。

| 快照对 | `fast` 预设的 worst \|diff\| | 结论 |
|---|---|---|
| `before` → `after` (加转速积分项) | **0** | 逐位不变 |
| `before` → `after2` (改变步长读取方式) | **0** | 逐位不变 |
| `before` → `after3` (改报告输出) | **0** | 逐位不变 |
| `before` → `after4` (加偏航阻尼块) | **0** | 逐位不变 |
| `before` → `after5` (全文件中文注释翻译) | **0** | 逐位不变 |
| `before` → `ws` (改用 `wheel_stop` 预设) | 有差异 | **预期**：那是另一套预设 |

判据是 `tol = 0`，即**逐位**。任何一次 `fast` 预设的行为发生偏移都会立刻暴露。
